## Tweet 2: Technical privacy insight

🧵 How our privacy model works:

1️⃣ Manufacturer creates a seal code → SHA-256 hash stored on-chain
2️⃣ Consumer has the raw seal code (printed on product)
3️⃣ To verify: consumer proves they know the preimage of the hash
4️⃣ ZK proof verifies authenticity WITHOUT revealing the code

The hash is public. The secret stays private. That's the power of zero-knowledge.
